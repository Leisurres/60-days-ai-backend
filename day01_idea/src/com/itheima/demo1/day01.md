## 核心知识点
- `.java` 是 Java 源代码文件。 
- `javac HelloWorld.java` 将源代码编译成 `.class` 字节码文件。
- `java HelloWorld` 启动 JVM 执行编译后的程序。
- public 类名必须与 Java 文件名一致。
- `.class` 文件是编译产物，不需要上传 GitHub。
