# 2. 原码/反码/补码

### 原码

1个字节(计算机中最小存储单元)8个bit, 最左边是符号位, 正值符号位是0, 负值符号位是1

```java
\\一个字节最大值
01111111
```

原码弊端: 0 + 1 = 1; 10000000->10000001(变成-1)

数轴理解: 符号位标识向左跑or向右跑

### 反码: 解决原码不能计算负数的弊端

正数->反码不变; 负数: 符号位不变, 数值取反(0变1, 1变0)

反码弊端: 不跨0不会有误差, 跨0有1位误差

### 补码: 解决反码跨0误差的弊端

正数->补码不变; 负数: 反码错/"加"一位是补码. eg. -0的补码是+0的反码, -1的补码是-0的反码

计算: 都拿补码算即可, 超出8位的不管. eg. -4+5-> 1111 1100 + 0000 0101 = 0000 0001->1, 结果正确

计算机中数字计算/存储都是以补码的形式

### 其他运算符

```java
// 1为true 0为false
int a = 200;    //  0000 0000 0000 0000 0000 0000 1100 1000
int b = 10;     //& 0000 0000 0000 0000 0000 0000 0000 1010
                //  0000 0000 0000 0000 0000 0000 0000 1000 
System.out.println(a & b);  // 8
//计算数字的逻辑& | 没有短路运算符
```

<< 左移: 向左移动 低位补0(左移1次 = *2)

\>> 右移: 向右移动 高位补0或1(数值位->0, 符号位: 保持与原数同符号) (右移1次 = /2)

\>>>无符号: 向右移动 高位补0

### switch语句

格式
```java
switch(){
    case 1: //这里的1需要是字面量, 不能是变量
        ...
        break;  //结束整个switch语句
    case 2:
        ...
    ...
    default:
        ...
        break;
}
```

case穿透: 无break情况 使用场景: 多个case语句体重复, 考虑用case穿透简化代码

if格式3: 范围判断; switch: 有限个数据列举任选1

### for循环

格式:
```java
for(int i = 1; i <= 10 ; i++ ){
    System.out.println("Helloworld!");
}
//()中是分号分割!
//int i, 这个int别忘了声明
```

### while循环

格式:
```java
int i = 1;
while(i <= 100){
    sout(i);
    i++;    //while别忘了增
}
```

for和while的区别:

for循环: 控制循环的变量在循环结束后无法被访问; while可以(不绝对)
```java
int i = 1;
for(; i <= 10 ; i++ ){
    System.out.println("Helloworld!");
}
```
业务中选择: 直到循环次数/范围->for循环; 不知道循环次数/范围, 但知道循环结束条件->while循环

eg. 折几次纸比珠峰高

- do...while

do{
    ...
}while{};
