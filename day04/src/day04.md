# 数组

### 概念
存储同种数据类型的多个值的容器(可以隐式转换, dflisb)

### 定义格式
格式1
```java
int[] array;
```
格式2
```java
int array[];
```

### 静态初始化
内存中为数组容器开辟空间, 并将数据存入容器的过程
```java
int array[] = new int[]{1, 2, 3};
double array2[] = {1.0, 2.0, 3};    //逗号隔开
```
- 
```java
sout(arr);  //[I@dfefds52s 数组的地址值(内存中位置) [: 数组 I: 元素int
```

### 访问数组元素
格式
```java
arr1[0]
```

### 数组遍历
数组名.length
```java
for(int i = 0, i < arr1.length, i++){
    sout(arr1[i]);
}
// 注意<
```
- 一个循环尽量只做一件事

### 动态初始化
初始化时只指定数组长度, 由系统为数组分配初始值

格式:
```java
int array[] = new int[10];
```

- sout, ln删掉就不会自动换行了.
```java
System.out.print(arr[i] + " ");
```

### 获取数组随机索引
```java
int randomIndex = r.nextInt(arr.length);
```

### 数组内存
- new 出来的都是存在堆中的; 方法是存在栈里, 通过地址调用堆中内容

```java
int[] arr1 = {11, 12};
int[] arr2 = arr1;  //数组地址值赋给arr2, 那两个数组记录的地址一样
```

# 方法

### What?
方法: 程序中最小的执行单元

将一些代码打包在一起, 需要用的时候就调用

### 格式

定义格式:
```java
public static void method(int num1, int num2){
...
}
```

调用格式:
```java
method(10, 20); //个数, 数据类型都要对应
```

3. 方法调用处是否需要继续使用方法的结果?

定义格式:
```java
public static int method2(int num1, int num2){
...
return xxx; //返回方法调用处
}
```

调用格式:
```java
method2(10, 20); //直接调用
int num = method2(10, 20); //赋值调用
sout(method2(10,20)); //输出调用
```

- 看到方法进入方法, 执行完毕回到调用处(方法内可以再调用方法)

- 方法定义时参数->形参; 方法调用时参数->实参

- 方法定义技巧:

1. 要干什么->方法体

2. 干这件事需要做什么才能完成->形参

3. (见上面返回参数方法定义)

- 方法与方法之间平级, 不能互相嵌套定义. (eg. 不能在main方法中定义方法)

- 一旦执行return, 方法就(返回+)结束了. 根据这个特点, 可以复习YunYong_07.java > chaZhao方法(黑马答案)

### 方法重载

同一个类中, 方法名相同, 参数不同(个数/类型/顺序). 不看返回值

相同功能的方法名取成一样的(重载, 不用手动选择)

### 方法内存

调用: 先进栈的压在下面, 后出栈.

引用数据类型: 变量中存的是地址值, 数据值存在其他空间中. -> 引用: 使用了其他空间中的数据

基本数据类型 -> 数据值存在自己空间中(赋给其他变量也是真实值)
